House Rent Prediction 

About the Project

This project uses Machine Learning to predict house rent based on property details such as BHK, size, city, furnishing status, bathrooms, and other features.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Random Forest Regressor

Features

- Data cleaning and preprocessing
- Categorical feature encoding
- Machine Learning model training
- Model evaluation using MAE, RMSE, and R²
- Interactive rent prediction through user input

Dataset

The project uses "House_Rent_Dataset.csv".

How to Run

1. Install Python.

2. Install the required libraries:
   
   "pip install pandas numpy matplotlib scikit-learn"

3. Run the project:
   
   "python main.py"
